# Checklist M1 — « Ça compile, ça se déplace, l'arène existe »

Objectif du jalon : projet UE5 compilable, personnage avec contrôles caméra WoW,
arène procédurale générée depuis le CSV. Aucun combat encore.

## Étapes éditeur (~5 minutes de clics)

1. `git pull`, puis clic droit `ArenaGame.uproject` → Generate Visual Studio project files.
2. Ouvrir `ArenaGame.sln` → **Development Editor | Win64** → Build.
   ⚠️ S'il y a des erreurs de compilation : **s'arrêter là et envoyer le texte complet à Claude.**
3. Lancer l'éditeur (F5). Il s'ouvre sur un niveau « Untitled » : normal, la map n'existe pas encore.
4. **File → New Level → Empty Level** (niveau vide, sans sol ni ciel).
5. **File → Save Current Level As…** → bouton clic droit dans `Content` → créer le dossier `Maps`
   → nommer le niveau **`L_Arena`** (chemin final exact : `Content/Maps/L_Arena`).
6. Redémarrer l'éditeur (il s'ouvrira directement sur L_Arena désormais).
7. Cliquer **Play** (PIE).

## Tests d'acceptation

Dans l'ordre — cocher mentalement, noter tout écart :

- [ ] L'arène apparaît : sol, 4 murs, 2 piliers cylindriques, 2 portes colorées (rouge à l'est, bleue à l'ouest), murets des alcôves de départ. Le ciel est noir : normal à ce stade.
- [ ] Le personnage (capsule bleue avec un petit cube noir indiquant l'avant) apparaît devant une porte.
- [ ] ZQSD : Z avance, S recule, Q/D straferaient, A/E tournent le personnage (défauts AZERTY).
- [ ] La reculade (S) est nettement plus lente que la marche avant (~45 %).
- [ ] **Clic droit maintenu** : la souris oriente le personnage (mouselook), le curseur disparaît.
- [ ] **Clic gauche maintenu** : la caméra orbite autour du personnage sans le tourner.
- [ ] Orbiter avec clic gauche, puis **presser clic droit** : le personnage s'aligne instantanément sur la caméra (comportement WoW).
- [ ] Molette : zoom caméra in/out ; la caméra ne traverse pas les piliers/murs (elle se rapproche).
- [ ] Espace : saut. Collision contre piliers et murs : on ne traverse rien.
- [ ] Console (`²`) → `Arena.ReloadData` : l'arène se reconstruit. Test complet : éditer
      `Content/Data/ArenaLayout.csv` (ex. déplacer un pilier : colonne X de PillarN), sauvegarder,
      relancer `Arena.ReloadData` → le pilier a bougé, sans recompilation.
- [ ] **Test réseau** : Editor Preferences → Level Editor → Play → Multiplayer Options :
      Number of Players = **2**, Net Mode = **Play As Listen Server** → Play.
      Deux fenêtres s'ouvrent, chaque joueur apparaît à une porte opposée, et chacun voit
      l'autre capsule bouger quand elle se déplace.
